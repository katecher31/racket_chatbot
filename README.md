# racket_chatbot
Rule-based chatbot project built in Racket/DrRacket for computer science coursework.
This project is a rule-based chatbot developed in Racket/DrRacket as part of introductory computer science coursework.
The assignment structure and project requirements were provided in class.
My completed version includes my implementation, response categories, code organization,comments and extensions.

## Project Overview

The chatbot processes user input and generates responses based on keyword recognition, conditional logic, randomized responses, and predefined conversational categories.

## Features

- Keyword recognition
- Conditional responses
- Randomized outputs
- User input processing
- Multiple response categories, including pets, hot beverages, music, movies, and weather
- Functional programming structure with helper functions
- Code documentation and debugging practice

## Technologies Used

- Racket
- DrRacket

## Purpose

This project helped me practice programming logic, functional programming concepts, list processing, helper functions, and rule-based response generation. It also introduced me to foundational ideas related to how simple conversational systems can process input and generate responses.
